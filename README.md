# The brand: website mockup

A static mockup of the human-editing service: landing page plus a client order screen.

## Run it
Open `index.html` in a browser, or in VS Code right-click it and choose "Open with Live Server".

## Files
- `index.html`: page content (home page and order screen)
- `css/styles.css`: all styling; colours are variables at the top (`--accent` is the main colour)
- `js/main.js`: live word count and price at $0.10 per word

## Change the brand name
Search for `The brand` (Ctrl+H) and replace it in `index.html`, including the page `<title>`.

## What works and what doesn't
Works: nav links, tabs, live word count and total.
Mock only: payment, Word upload counting, time-lapse video, and the order list. These need a real back end: login, payments, file and video storage, and an editors' area.
